# GitHub Pages 대시보드

접속 주소: https://namonu71.github.io/project_chungmu/index.html

저장소 루트의 `index.html`이 대시보드 진입점입니다. `pages/assets`에 미리 빌드한 스크립트와 스타일을 포함하므로 GitHub Pages에서는 별도의 서버나 설치 없이 열립니다.

가상 주문 12건으로 시작하며, 검수·결과물 생성·송장 대조를 브라우저에서 체험할 수 있습니다. 변경 기록과 생성 파일은 해당 브라우저의 IndexedDB에만 보관합니다. 여러 기기나 사용자 사이에 동기화하지 않으며 기존 업무용 웹앱과도 데이터를 공유하지 않습니다. 민감한 실제 주문을 넣는 용도로 공개 체험 페이지를 사용하지 마세요.

`실제 업무용 웹앱 열기`는 로그인과 서버 저장소를 사용하는 기존 웹사이트로 연결됩니다.

재생성하려면 웹 의존성을 설치한 뒤 프로젝트 루트에서 실행합니다.

```bash
node pages/build.mjs
```

빌드는 PC 대시보드 UI와 웹 업무 처리 모듈을 사용합니다. GitHub Pages 체험판은 별도 백엔드/API에 주문 데이터를 보내지 않습니다.
